About

I am a backend developer working mostly with Laravel. My projects range from payment integration and a mobile REST API to a large public-sector dataset, multi-institution integrations, and vendor management systems. In recent projects I also acted as project PIC for small teams, reviewed code, and added testing to the workflow.

A note on the code you will see here. The showcase repos are built from scratch with a fictional domain to show patterns I use in production. They contain no employer or client code, names, schemas, data, or screenshots. Benchmark numbers come from fictional data on one machine and are not numbers from any client system.
